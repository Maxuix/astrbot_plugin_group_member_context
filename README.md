## 核心功能

- **群级身份资料**：每个平台实例、每个 QQ 群独立保存成员资料和自定义身份字段。
- **多种称呼映射**：支持外号、真名、昵称、群名片和自定义身份字段。
- **群内身份管理**：通过 `/群身份` 添加、删除和查看身份，并按群开启或关闭注入。
- **图片身份卡**：`/群身份 list` 使用与插件 WebUI 一致的卡片风格图片展示成员身份。
- **动态上下文注入**：只注入近期消息中发言或被提到的已配置成员，不注入整个群成员列表。
- **可编辑使用规则**：每个群拥有独立的【使用规则】，可在默认规则上修改、追加或一键恢复。
- **头像预览**：可选显示当前页成员头像，默认关闭，不会写入 Prompt。
- **WebUI 管理**：支持权限名单、群管理员候选、刷新成员、搜索、分页、筛选和重置当前群资料。

## 环境要求

- AstrBot
- OneBot V11 / `aiocqhttp`
- QQ 群会话

插件需要平台提供群列表、群成员列表和群成员信息接口，不需要额外安装 Python 或前端依赖。

## 安装

### 插件市场

在 AstrBot WebUI 的插件市场搜索“群成员身份上下文”并安装，安装或更新后重载插件。

### 手动安装

将仓库目录复制到：

```text
AstrBot/data/plugins/astrbot_plugin_group_member_context/
```

然后重启 AstrBot，或在 WebUI 中重载插件。

## 快速开始

1. 在 AstrBot 中连接并启用 OneBot V11 / `aiocqhttp`。
2. 打开「插件 → 插件页面 → 群成员身份上下文」。
3. 选择 QQ 群并刷新成员列表。
4. 在成员卡片中填写需要让模型识别的身份资料。
5. 点击「保存本群设定」。
6. 在群内触发一次 LLM 请求，验证身份上下文是否生效。

刷新成员会从 OneBot 获取最新的平台昵称、QQ 号和群名片，并按 QQ 号匹配已保存的资料。

## 成员资料

| 字段 | 说明 |
| --- | --- |
| 平台昵称、QQ 号、群名片 | 从 OneBot 获取，用于展示和匹配。 |
| 外号 | 可填写多个常用称呼。 |
| 真名 | 可填写多个真实姓名或英文名。 |
| 昵称 | 可填写多个游戏昵称、网名等。 |
| 自定义身份字段 | 自定义字段名，例如“游戏名”“部门”“花名”。 |
| 补充说明 | 记录需要模型理解的其他信息。 |

只有填写了身份资料的成员才会参与身份映射。成员资料按当前 QQ 群保存，不会与其他群混用。

### 自定义身份字段

自定义字段名和字段值都按平台实例及 QQ 群隔离。例如在一个群中定义「游戏名」，不会让其他群自动出现该字段。升级旧版本时，已有全局字段会迁移到每个已有群。

### 编辑本群使用规则

页面中的使用规则编辑框默认填充插件内置规则。你可以直接修改或追加内容，也可以点击「重置为默认」恢复内置规则。修改后需要点击「保存本群设定」，并且只会影响当前 QQ 群。

### 群指令与页面同步

群指令和插件页面读写同一份资料。页面会定期检查资料版本：没有未保存编辑时自动载入群指令产生的更新；存在本地编辑时提示先刷新。保存和重置操作会校验版本，避免旧页面覆盖新资料。

## Prompt 注入逻辑

插件只在 AstrBot 产生 LLM 请求时执行：

- 检索最近一段群消息，范围由「动态成员消息窗口数量」控制。
- 识别窗口内发言过，或在消息中被提到的成员。
- 只注入已配置身份资料的成员，并对重复命中进行去重。
- 支持通过平台昵称、群名片、外号、真名、昵称和自定义身份字段理解称呼。

插件不会自动注入未配置成员、当前消息窗口之外的成员，也不会根据平台角色或其他身份标签推断成员关系。

## 配置

插件页面左侧配置栏与 AstrBot 插件配置菜单共用同一份配置。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 动态成员消息窗口数量 | `20` | LLM 请求时检索的最近消息数量，范围为 `1～200`。 |
| LLM 注入日志详细程度 | `摘要` | 「全部」会额外记录本次完整注入 Prompt，请注意其中可能包含身份资料。 |
| 开启头像预览 | `关闭` | 显示当前分页成员头像，不会写入 Prompt。开启后会访问 QQ 头像 CDN。 |
| 群身份管理员指令白名单 | 留空 | 非空时只有列表中的 QQ 号可执行管理员指令，并忽略黑名单。 |
| 群身份管理员指令黑名单 | 留空 | 仅在白名单留空时生效，名单中的 QQ 号不能执行管理员指令。 |
| 允许普通群成员使用管理员指令 | `关闭` | 关闭时只有群主和群管理员具备基础资格；开启后普通成员也具备基础资格。 |

WebUI 会根据当前群成员资料生成群主和管理员候选，可直接加入白名单或黑名单；也可以在 AstrBot 原生插件配置中手动填写 QQ 号。两处配置共用并同步同一份数据。

头像预览只处理当前分页，头像加载失败时会保留文字占位，不影响成员资料和 Prompt 注入。

## 群身份指令

所有指令仅在当前 QQ 群生效。未填写标签时默认使用「昵称」；显式标签使用 `标签=身份`，身份内容可以包含空格。

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/群身份 add @成员/QQ 身份` | 管理员 | 为目标成员添加昵称。 |
| `/群身份 add @成员/QQ 标签=身份` | 管理员 | 添加指定身份；标签不存在时创建为本群自定义标签。 |
| `/群身份 remove @成员/QQ [标签=]身份` | 管理员 | 精确删除目标成员的身份。 |
| `/群身份 me [标签=]身份` | 普通成员 | 给自己添加身份，只能使用内置标签或本群已有自定义标签。 |
| `/群身份 merm [标签=]身份` | 普通成员 | 删除自己的身份。 |
| `/群身份 list [@成员/QQ]` | 普通成员 | 以图片卡片查看成员身份；省略目标时查看自己。 |
| `/群身份 on` / `/群身份 off` | 管理员 | 开启或关闭当前群的身份注入，不删除资料。 |
| `/群身份 help` | 普通成员 | 查看指令帮助。 |

管理员指令首先检查发送者是否为当前群的群主或管理员；开启「允许普通群成员使用管理员指令」后，普通成员也具备基础资格。白名单非空时必须同时位于白名单，且黑名单不生效；白名单留空时再应用黑名单。

目标必须是真实 QQ `@` 消息段或当前群成员 QQ 号；不接受手打的 `@昵称`、`@全体成员` 或非本群 QQ。指令只返回简短成功或失败结果，失败时附带原因。

## 数据与隐私

- 成员资料使用 AstrBot 插件 KV 存储，不写入插件目录。
- 不同平台实例和 QQ 群之间相互隔离。
- 图片身份卡不会展示成员的「补充说明」。
- 头像预览默认关闭；开启后需要访问 QQ 头像 CDN。
- 「全部」日志模式可能记录完整 Prompt，请按实际隐私要求启用。

## 常见问题

### 页面没有可选群

确认 OneBot V11 / `aiocqhttp` 已连接，机器人仍在目标群内，并具有获取群列表和群成员列表的权限。

### 成员资料没有注入

确认当前群的身份注入已开启、成员至少填写了一项身份资料，且该成员在最近消息窗口中发言或被提到；插件只在实际触发 LLM 请求时注入。

### 群指令提示没有权限

确认发送者具备群主或群管理员身份，并检查管理员指令白名单、黑名单和普通成员权限开关。白名单非空时，发送者必须在白名单中。

### 头像无法加载

确认已开启头像预览，并检查 AstrBot 所在主机和浏览器是否能够访问 QQ 头像 CDN。头像功能不影响成员身份上下文功能。
